## 3. Reddit r/ClaudeAI (draft)

Titolo:
```
[Tool] mcp-google-sheets-full — a Google Sheets MCP with a code-execution escape hatch
```

Corpo:
```
I built and published a Google Sheets MCP server that fills a gap I kept hitting with the existing ones: they expose a fixed set of tools, so anything they didn't anticipate is out of reach.

This one has 26 dedicated tools for the common cases (read/write/append/clear, batchUpdate, structural ops like add/delete/duplicate sheets, format, borders, merge, Drive search, etc.) plus one extra primitive: `run_sheets_script` — you pass a chunk of Node code, the harness pre-authenticates `sheets`/`drive`/`auth`/`spreadsheetId`, runs it in a temp file, and returns the result. The temp file is always cleaned up.

Auth is OAuth Desktop (user account), not service account — so no IAM dance, no sharing the sheet with a robot email. The first run opens a browser, after that it just works.

Install:
    npm install -g mcp-google-sheets-full
    claude mcp add google-sheets -- mcp-google-sheets-full --scope user

There's an AGENTS.md in the repo with the canonical setup flow if you want Claude itself to install + configure it.

Repo: https://github.com/moooonad/mcp-google-sheets-full
npm: https://www.npmjs.com/package/mcp-google-sheets-full
MCP registry: io.github.moooonad/mcp-google-sheets-full

Feedback welcome.
```
